# launcher: المشغّل

برامج التجهيز والفحص والتشغيل.

| الملف | ماذا يفعل |
|---|---|
| `hima_start.py` | المشغّل: يجهّز الجهاز ويفحص كل شيء قبل الرحلة، أو يشغّل المحطة مع `--station` |
| `start.sh` | تشغيل المشغّل على الجيتسون: `bash launcher/start.sh` |
| `start.bat` | تشغيل المشغّل على Windows بنقرتين |
| `start_station.bat` | تشغيل المحطة على Windows: الاستقبال واللوحة |
| `start_station.sh` | تشغيل المحطة على Linux |
| `link_tests.py` | اختبارات الاتصال بالبيكس هوك والكاميرا والمحطة (14 اختبارًا) |
| `link_ui.py` | صفحة في المتصفح تعرض اختبارات الاتصال خطوة بخطوة |
| `test_links.sh` | تشغيل اختبارات الاتصال على الجيتسون |
| `test_links.bat` | تشغيل اختبارات الاتصال على Windows |
