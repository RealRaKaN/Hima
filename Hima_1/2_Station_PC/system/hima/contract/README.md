# contract: شكل الملفات

كل ملف ينتقل بين الدرون والمحطة له مخطط هنا، ويُرفض أي ملف لا يطابقه.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | ثوابت ملف الجلسة |
| `io.py` | قراءة ملف الجلسة والتحقق منه وحفظه بأمان |
| `session.schema.json` | مخطط ملف الجلسة (الإطارات والتحليل) |
| `package.py` | التحقق من حزمة المهمة وملفاتها |
| `package.schema.json` | مخطط ملف الحزمة |
| `report.schema.json` | مخطط تقرير الهبوط |
| `advice.schema.json` | مخطط رد النموذج لكل حيوان |
| `judge.schema.json` | مخطط رد النموذج الذي يراجع جمل التقرير |
| `delivery.py` | ما يشترك فيه الدرون والمحطة في النقل: المفتاح والتوقيع |
