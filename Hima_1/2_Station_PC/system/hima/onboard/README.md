# onboard: على متن الدرون

ما يعمل أثناء الرحلة وبعد الهبوط على الجيتسون.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | تعريف الحزمة |
| `flight.py` | يجمع حلقة الرحلة: التحليل، والتنبيهات، والأجسام، والذكاء الاصطناعي، والرسائل |
| `loop.py` | يحدّث التحليل كل update_s أثناء وصول الإطارات |
| `alerts.py` | تنبيهات الحيوانات بقواعد ثابتة (SEVERE، INJ1-3، PROXIM، YOUNG) |
| `dwell.py` | مدة بقاء الدرون فوق حيوان واحد (DWELL) |
| `objects.py` | الأجسام الغريبة من النموذج العام، وتنبيه المركبة |
| `ai.py` | الباب الوحيد إلى نماذج الذكاء الاصطناعي، وفحص كل جملة قبل إرسالها |
| `ai_line.py` | خط مستقل للذكاء الاصطناعي حتى لا ينتظره YOLO |
| `periodic.py` | تحليل دوري للأرقام كل 30 ثانية، بلا صور |
| `window.py` | نافذة الكاميرا: صور قليلة للنموذج عند حدث مهم فقط |
| `link.py` | قناة الرسائل النصية إلى المحطة (حد 50 بايت لكل رسالة) |
| `rawlog.py` | الملف الخام: كل إطار وكل صندوق وكل رسالة، بلا تحليل |
| `triage.py` | يختار ما يحفظه الدرون للمحطة |
| `media.py` | يقص المقاطع والصور من فيديو الرحلة |
| `packager.py` | يبني حزمة المهمة بعد الهبوط |
| `report.py` | تقرير الهبوط: النموذج يكتب، والبوابة تفحص كل رقم |
| `report_facts.py` | حقائق إضافية للتقرير: المجموعات والمركبات وسبب الاضطراب |
| `report_story.py` | حقائق التقرير السردي: مراحل الرحلة والحوادث والمتابعة |
| `deliver.py` | يرسل الحزمة إلى المحطة عبر الواي فاي بعد الهبوط |
