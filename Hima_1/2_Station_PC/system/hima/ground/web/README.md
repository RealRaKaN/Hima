# web: لوحة المتابعة

خادم صغير على هذا الحاسوب فقط (localhost)، بلا إنترنت.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | تعريف الحزمة |
| `server.py` | خادم الويب: يقدّم الصفحات والملفات |
| `api.py` | البيانات التي تطلبها الصفحات (JSON) من الأرشيف |
| `static/` | ملفات الصفحة نفسها: HTML وCSS وJavaScript |
