# static: ملفات الصفحة

ما يفتحه المتصفح. بلا مكتبات خارجية.

| الملف | ماذا يفعل |
|---|---|
| `index.html` | هيكل الصفحة والقائمة الجانبية |
| `app.css` | الألوان والخطوط والثيم الفاتح والداكن |
| `core.js` | أدوات مشتركة: الأيقونات، وطلب البيانات، والتنسيق |
| `main.js` | التنقل بين الصفحات والتحديث كل 3 ثوانٍ |
| `pages.js` | صفحات Overview وMission وCompare وReview |
| `charts.js` | الرسوم البيانية والخريطة |
| `route.js` | صفحة Route: الطريق قبل الإقلاع |
