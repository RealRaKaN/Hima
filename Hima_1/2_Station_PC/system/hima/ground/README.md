# ground: المحطة الأرضية

ما يعمل على حاسوب المحطة.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | تعريف الحزمة |
| `receiver.py` | يستقبل حزم الدرون عبر الواي فاي ويتحقق منها ويضيفها إلى الأرشيف |
| `archive.py` | الأرشيف: إدخال الحزم بعد فحصها، وفهرس الرحلات |
| `mission.py` | بيانات رحلة واحدة لصفحة Mission في اللوحة |
| `compare.py` | مقارنة رحلات أو أيام، وتصفية الأرشيف بالتاريخ |
| `stats.py` | إحصاءات عبر كل الرحلات |
| `review.py` | تصدير الصور غير المؤكدة بصيغة YOLO لإعادة التدريب |
| `demo.py` | يضيف الرحلات الافتراضية إلى الأرشيف حتى لا تفتح اللوحة فارغة |
| `plans.py` | عروض الطريق قبل الإقلاع: ما أرسله الدرون، ورد المحطة، والنتيجة |
| `routes.py` | منطق صفحة Route: فحص الطريق المعدّل وإرساله |
| `route_radio.py` | جسر الراديو لعروض الطريق، إذا لم يكن عند الدرون واي فاي |
| `imagery.py` | صور الأقمار تحت خريطة الطريق: إضافتها وقراءتها |
| `web/` | لوحة المتابعة في المتصفح |
| `route_map/` | خريطة تعديل الطريق |
