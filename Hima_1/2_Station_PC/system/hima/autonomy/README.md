# autonomy: الاستقلال الذاتي

الدرون يختار طريقه قبل الإقلاع، ويقرر أثناء الطيران متى يلحق قطيعًا أو مركبة. بلا ذكاء اصطناعي.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | تعريف الحزمة |
| `reserve.py` | حدود المحمية، والسياج داخلها، وشبكة المربعات، ونقاط الإقلاع |
| `history.py` | سجل الرحلات السابقة: المسارات والقطعان وحوادث الصيد |
| `planner.py` | يختار طريق اليوم من نقطة الإقلاع وإليها حسب الطاقة |
| `export.py` | يكتب الخطة ملفات لأردو بايلوت (المهمة والسياج والمعاملات) وصورة SVG |
| `review.py` | يعرض الطريق على المحطة قبل الإقلاع ويستقبل التعديل |
| `behaviour.py` | القرار أثناء الطيران: يلحق القطيع أو المركبة، أو يكمل الطريق، أو يرجع |
| `executor.py` | ينفّذ القرار على الطيار الآلي: الأوضاع، ونقاط GUIDED، ورفع الخطة، وفحص معاملات السلامة |
| `onflight.py` | يربط كل ما سبق بالرحلة الحية (يستدعيه fly.py) |
| `rangers.py` | يميّز مركبات المحمية حتى لا تُلاحق (مطفأ الآن) |
| `geodesy.py` | تحويل خطوط الطول والعرض إلى أمتار على مستوى المحمية |
| `polygon.py` | حسابات المضلعات (داخل أو خارج، تبسيط، إزاحة) |
