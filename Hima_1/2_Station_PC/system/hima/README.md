# hima: كود النظام

الحزمة الرئيسية. كل الأوامر تبدأ بـ `python -m hima <أمر>`.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | اسم الحزمة ووصفها |
| `__main__.py` | سطر الأوامر: كل أوامر `python -m hima` (fly، preflight، plan، receive، deliver، dashboard...) |
| `config.py` | يقرأ `hima.toml` ويتحقق من كل قيمة |
| `fly.py` | الرحلة الحية على الدرون: الفحص قبل الإقلاع، وانتظار التسليح، والحلقة حتى الهبوط، ثم الحزمة |
| `e2e.py` | رحلة كاملة مصطنعة من البداية إلى الأرشيف، لفحص النظام على الحاسوب |
| `evaluate.py` | يقارن الحالات المحسوبة بالحقيقة في الرحلات المصطنعة فقط |
| `advisor/` | الاتصال بنموذج اللغة (Ollama) والتحقق من ردوده |
| `analytics/` | الحسابات الثابتة: المسارات والسرعة والأحداث والحالات |
| `autonomy/` | الاستقلال الذاتي: الطريق قبل الإقلاع والقرار أثناء الطيران |
| `contract/` | شكل الملفات (مخططات JSON) والتحقق منها، ومفتاح النقل |
| `dashboard/` | جداول البيانات التي تعرضها لوحة المحطة |
| `ground/` | المحطة الأرضية: الاستقبال والأرشيف واللوحة ومراجعة الطريق |
| `onboard/` | ما يعمل على متن الدرون: التنبيهات والذكاء الاصطناعي والتقرير والحزمة والإرسال |
| `sources/` | مصادر الصور: الكاميرا، وملف فيديو، والمولّد المصطنع، ومسجّل الجلسة |
| `telemetry/` | الاتصال بالبيكس هوك عبر MAVLink |
