# demo: الرحلات الافتراضية

تُضاف إلى الأرشيف عند تشغيل المحطة حتى لا تفتح اللوحة فارغة. ليست رحلات حقيقية، وتظهر في اللوحة بعلامة Virtual. لا تعدّل ملفات الحزم: المحطة تتحقق من بصمة كل ملف.

| الملف | ماذا يفعل |
|---|---|
| `flight-20261115T151622Z/` | حزمة رحلة محاكاة كاملة: `package.json` (قائمة الملفات وبصماتها)، و`session.json` (الإطارات والتحليل)، و`report.json` (التقرير)، و`flight_log.json` (سجل الطيران)، و`clips/` (مقاطع)، و`images/` (صور)، و`uncertain/` (صور غير مؤكدة) |
| `more/` | 8 رحلات مصطنعة إضافية لصفحة المقارنة، كل مجلد حزمة بنفس الشكل |
| `route_offer.json` | طريق تجريبي يظهر في صفحة Route |
