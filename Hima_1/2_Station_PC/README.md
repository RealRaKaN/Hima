# 2_Station_PC: المحطة الأرضية

انسخ هذا المجلد كاملًا إلى حاسوب المحطة (Windows).

| الملف | ماذا يفعل |
|---|---|
| `START_STATION.bat` | تشغيل المحطة بنقرتين: الاستقبال ولوحة المتابعة |
| `HOW_TO_RUN_STATION.md` | خطوات التشغيل على حاسوب المحطة |
| `system/` | الكود والإعدادات والمفتاح |
| `data_ext/` | حدود المحمية، وصور الأقمار، والرحلات الافتراضية |
