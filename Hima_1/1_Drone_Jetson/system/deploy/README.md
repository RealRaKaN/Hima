# deploy: خدمات الجيتسون

تُثبَّت بالأمر `bash launcher/start.sh --install-service`.

| الملف | ماذا يفعل |
|---|---|
| `hima-fly.service` | خدمة تشغّل برنامج الرحلة عند تشغيل الجيتسون، وتنتظر التسليح |
| `hima-deliver.service` | خدمة ترسل حزمة المهمة إلى المحطة بعد كل هبوط |
| `setup_jetson.sh` | تجهيز الجيتسون وتثبيت الخدمتين (يستدعي المشغّل) |
