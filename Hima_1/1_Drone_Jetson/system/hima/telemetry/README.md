# telemetry: البيكس هوك

الاتصال بالطيار الآلي (أردو بايلوت).

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | تعريف الحزمة |
| `mavlink.py` | قراءة موقع الدرون وحالته، وإرسال الرسائل النصية، عبر MAVLink 2 |
| `mission.py` | رفع المهمة والسياج وقراءتهما من الطيار الآلي |
| `geo.py` | تحويل خطوط الطول والعرض إلى أمتار حول نقطة البداية |
