# analytics: الحسابات

حسابات ثابتة بلا ذكاء اصطناعي: نفس المدخلات تعطي نفس النتيجة دائمًا.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | تعريف الحزمة |
| `analyze.py` | يبني قسم التحليل في ملف الجلسة من الإطارات |
| `behavior.py` | الوقت المرئي، والحركة والسكون، والاختباء تحت الشجر، والمسافة المقطوعة |
| `events.py` | الأحداث كفترات زمنية (بداية ونهاية) |
| `geometry.py` | تحويل نقطة في الصورة إلى موقع على الأرض (كاميرا تنظر للأسفل) |
| `herd.py` | تماسك القطيع، والحيوان المعزول، ومسافة الدرون |
| `identity.py` | أي الصناديق حيوان واحد: يدمج المسارات المنقطعة ويحذف صناديق الأجزاء |
| `movement.py` | أين وُجد كل حيوان بعد الهبوط، مع موقعه GPS |
| `status.py` | حالة كل حيوان (طبيعي، مضطرب، مصاب محتمل...) بقواعد ثابتة |
| `tracks.py` | مواقع كل مسار على الأرض وسرعته |
