# advisor: نموذج اللغة

النموذج يقترح، والكود يقرر. لا يصل رد النموذج إلى الدرون إلا بعد الفحص.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | تعريف الحزمة |
| `advise.py` | يطلب من النموذج اقتراحًا لكل حيوان ويكتبه في ملف الجلسة |
| `gate.py` | البوابة: تقرر هل يُقبل رد النموذج أو يُرفض |
| `ollama_client.py` | الاتصال بخادم Ollama المحلي (إرسال الطلب، وتحميل النماذج وإنزالها) |
| `policy.py` | جدول الأوامر المسموحة لكل حالة حيوان، والأمر الافتراضي |
| `prompt.py` | يكتب نص الطلب للنموذج من أرقام حيوان واحد |
