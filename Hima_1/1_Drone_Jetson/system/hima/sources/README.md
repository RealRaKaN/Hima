# sources: مصادر الصور

تكتب المشاهدات الخام فقط (الإطارات والصناديق)، بلا حسابات.

| الملف | ماذا يفعل |
|---|---|
| `__init__.py` | تعريف الحزمة |
| `camera.py` | كاميرا الدرون: تقرأ الإطارات وتعطي الأحدث دائمًا |
| `video.py` | ملف فيديو بدل الكاميرا: YOLO والتتبع ثم ملف الجلسة |
| `recorder.py` | يجمع المشاهدات إطارًا بإطار ويكتب ملف الجلسة |
| `synthetic.py` | مولّد رحلات مصطنعة للفحص |
